Project aim

The goal of this project is to automatically annotate traffic videos. These annotated videos could be used as demonstration material for self-driving car marketing by highlighting the detection of surrounding vehicles, traffic lights, and pedestrians. The objective is to help increase customer confidence in self-driving technologies.

The first target users are expected to be relatively tech-oriented. For this reason, car-brand recognition was also added to make the videos more engaging and entertaining.

To achieve this goal, the following sub-objectives were identified:

  • Detect driving-scene objects
  • Recognize car brands for each detected vehicle
  • Generate scene captions for viewers
  • Provide a simple Q&A interface for selected timestamps

Project structure

Detect driving-scene objects

A YOLOv10 model is used to detect predefined objects in driving scenes. The model is fine-tuned on an annotated dataset. With the selected dataset, 11 object classes are available:

  • biker
  • car
  • pedestrian
  • trafficLight
  • trafficLight-Green
  • trafficLight-GreenLeft
  • trafficLight-Red
  • trafficLight-RedLeft
  • trafficLight-Yellow
  • trafficLight-YellowLeft
  • truck

The resulting labels and bounding boxes are displayed on both test images and test videos.

Per-vehicle car-brand recognition

An OpenCLIP model is evaluated on a car-brand dataset. A linear probe is then trained on top of the OpenCLIP embeddings using the same dataset, and its performance is evaluated as well.

Based on the output of the YOLO model, car brands are predicted using the CLIP-based classifier. Whenever YOLO detects an object classified as a “car”, the corresponding bounding box is cropped from the image and passed to the CLIP model. The model then predicts the most likely brand among the brands used during fine-tuning.

The final prediction is selected using the highest softmax score. However, a minimum confidence threshold must be reached before displaying the predicted brand. If the threshold is not met, the label shown on the output video remains simply “car”.

Scene and audience-friendly captions

A Vision Language Model (VLM) running locally through Ollama is used to generate captions for the video. A new caption is created only if the current frame differs enough from the previous one or if enough time has passed since the last caption was generated.

This approach helps avoid producing too many repetitive captions while still providing useful scene descriptions.

Simple Q&A interface for selected timestamps

Single frames can be extracted from the video based on a selected timestamp. These frames are then passed to the VLM, which can either generate a caption or answer a user’s question about the scene.

This functionality is implemented through a simple user interface embedded directly in a Jupyter notebook.

Data

  • Self-driving videos with YOLO-compatible annotations
    • contains 11 classes
    • published by Roboflow
    • contains approximately 15,000 annotated images
  • Car brand dataset
    • contains 20 car brands
    • includes several models per brand, although only the brand information was used in this project
    • contains approximately 87,000 images, with between 350 and 14,000 images per brand
